## 🚀 How to Push to Your GitHub Repository

If you already have the repository cloned on your machine, copy these files into your folder and run:

```bash

git status

# 2. Add all modified and new files
git add index.html resume.html style.css script.js README.md

# 3. Commit changes
git commit -m "feat: complete portfolio redesign with terminal theme, projects, and GenAI certification"

# 4. Push to GitHub master/main branch
git push origin master
```

## 🌐 Free 1-Minute Deployment Options

### Option 1: Cloudflare Pages (Recommended - Same as your senior's setup)
1. Go to [pages.cloudflare.com](https://pages.cloudflare.com/) and log in.
2. Click **Create a project** > **Connect to Git**.
3. Select your repository `Aadii0916/Portfolio`.
4. Leave build settings empty (since it's pure HTML/CSS/JS) and click **Save and Deploy**.

### Option 2: GitHub Pages
1. Go to your repository on GitHub: `https://github.com/Aadii0916/Portfolio/settings/pages`.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select `master` (or `main`) and `/ (root)`, then click **Save**.
